Tiny chess engine — alpha-beta + null-move R=3. A chess engine in 4 KB of Python: alpha-beta search with quiescence, killer-move ordering, check extensions and null-move pruning (R=3), MVV-LVA move ordering, and a fixed 8,000-node budget per depth. Pure Python 3 standard library, no dependencies.

## Run it

```sh
python3 main.py
```

The engine connects to the make.fun game server from `MAKEFUN_ENV_URL` and plays as a bot.
